# Hoard 2 phase 2c: culling at parity, the Files gaps, the parity audit (ADR 0019)

- **Date**: 2026-11-14
- **Host**: cachyos-fps (Linux, OpenJDK 21, Android SDK in `~/Android/Sdk`), Gradle `-Xmx3g`, `--max-workers=4`
- **Device**: Android emulator `Pixel_API_36` (API 36, x86_64, 1080×2400), `-memory 3072 -no-window`, with the data
  imported in phase 2a; its virtual SD card (`sm set-virtual-disk true`, `sm partition disk:7,432 public`)
- **Server**: the culling Samba of `docs/testing/xmp-sidecars/samba/` (container `hoard-smb-2c`, 256 MB, 1 CPU,
  `127.0.0.1:4461`, reached at `10.0.2.2:4461`): `photos` writable and `photos-ro` read-only, both on the same folder
- **Photos** (never committed): 240 shots in `shoot/`. 220 RAW+JPEG pairs `DSC00001`–`DSC00220` made from one CC0
  Sony ILCE-6000 RAW from raw.pixls.us (`DSC01542.ARW`, a landscape): reflink copies with the EXIF date strings
  patched, 10 s apart except 6 bursts of 4 frames 1 s apart; the JPEGs are its 1616 px preview upscaled to
  3000×2000 with the date set. 20 JPEG-only shots `IMG00221`–`IMG00240` with problems for the assist: 8 blurred
  (σ 6 px), 4 darkened, 4 brightened, 4 clean.
- **Reveal**: Reveal's debug APK (`dev.hfps.reveal.debug`), emulator only

## Not verified

- A real phone or tablet, a hardware keyboard (keys were sent with `adb shell input keyevent`), a real USB OTG drive,
  and a volume reached only through SAF.
- Closed-eyes flags on real faces (the CC0 photo has none; the rules are JVM-tested and the ML Kit path is
  `:core:image`'s, unchanged).
- The language applied from an imported `language` row on a real upgrade (JVM-tested parsing; the mirror is new in this
  PR, so no Hoard 1 database has the row yet).
- Reveal opening the photos: its debug build crashed in its own editor in 2b; this run only checks the hand-off.
