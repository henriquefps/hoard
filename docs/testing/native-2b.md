### Edit in Reveal: the intent

```
START u0 {act=dev.hfps.reveal.action.DEVELOP typ=image/* flg=0x41 pkg=dev.hfps.reveal.debug
  clip={image/* application/rdf+xml 2 items: {U(content)} {U(content)}} (has extras)}
HoardFiles: Edit in Reveal: 1 photos, 1 sidecars, culling 0
UriPermission content://dev.hfps.hoard.next.stream/h/63e6…/5b97…%2FDSC0002.JPG  mode=0x1 persistable=0x1 persisted=0x1
UriPermission content://dev.hfps.hoard.next.stream/h/52ef…/5b97…%2FDSC0002.xmp  mode=0x3 persistable=0x3 persisted=0x3
```

One package (the debug Reveal, no chooser), read + persistable on the intent and no write flag, the photo as a stable
`/h/<id>/<tag>%2F<name>` link, the sidecar writable through `grantUriPermission` (`cullSaveXmp` is on), both persisted
by Reveal. `CULLING` was not sent: the folder has no culling decisions (the extra is built from `cull_decisions` of the
folder exactly as Hoard 1). Reveal's own debug build then crashed in its editor (`NoSuchMethodException:
EditorViewModel.<init> []`), a Reveal issue outside this PR.
